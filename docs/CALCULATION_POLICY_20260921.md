# 2026-09-21 熱量與價格計算規則

## 熱量

1. 主要食材與調味料分開計算。
2. 主要食材缺少可計算熱量的筆數比例 `> 20%` 時，主要食材熱量預設為 `NULL`。
3. 上述缺值比例雖然 `> 20%`，但目前已成功計算的主要食材熱量 **嚴格大於 500 kcal** 時，仍保留已知主要食材熱量。
4. 蔥、薑、蒜、辣椒、香菜、九層塔、紅蔥頭與條件式辛香佐料等 `AROMATIC`：
   - `< 80g`：不加入主要食材 20% 缺值比例。
   - `>= 80g`：視為主要食材，加入 20% 缺值比例。
5. `SPICE` 乾燥香辛料不加入主要食材 20% 缺值比例。
6. 調味料無法取得 `weight_g` 時，不加入調味料熱量。
7. 普通調味料：`weight_g < 50g` 不列入熱量；`>= 50g` 才計算。
8. 高熱量調味料（油脂、糖類、高熱量醬料）：`weight_g < 20g` 不列入熱量；`>= 20g` 才計算。
9. 最終熱量：
   - 主要食材熱量為 `NULL` → 最終熱量必為 `NULL`。
   - 主要食材有值、調味料無可計算值 → 顯示主要食材熱量。
   - 兩者都有值 → 相加。

## 價格

1. 每個食材獨立使用：`weight_g / 100 × 每100g價格`。
2. 每一個食材價格在顯示與加總前，先 **無條件進位到整數**。
3. 沒有價格資料或無法換算 `weight_g`：該食材顯示 `$無資料`。
4. 總金額為「所有成功計算、且已無條件進位後的單項價格」加總。
5. 全部食材都無法計算價格時：總金額顯示 `$無資料`。
6. 價格缺值不會使其他已知價格失效。

## API 顯示

`GET /api/v1/recipes/<seq>` 的每個 `ingredients[]` 項目新增：

- `estimated_price`: 整數價格，無資料時為 `null`
- `price_display`: `$12` 或 `$無資料`
- `display_text`: 原始食材文字後直接附上價格

食譜層級新增/調整：

- `estimated_price`: 已知單項價格（進位後）加總
- `total_price_display`: `$185` 或 `$無資料`

總金額欄位與熱量欄位一起回傳，供 Hermes / 前端在熱量下方顯示。
